description=[h2]Current Features[/h2]
description=[list]
description=[*]Live-refreshing combined proximity inventory built from vanilla-reachable nearby containers
description=[*]Live-refreshing Equipped inventory view for worn, held, and attached items
description=[*]Device-owned context submenus for supported device actions
description=[*]Optional battery and watch presentation adapters for the legacy powerWorks provider contract
description=[*]Exact-minute digital clocks and expanded military-watch information
description=[*]Automatic key-ring filing
description=[*]Bounded configurable inventory sorting with postcondition-verified server transfers
description=[*]Bulk magazine handling and crafting-output routing
description=[*]Hotbar reordering and map-symbol defaults
description=[*]Read and watched tracking plus reward hints for literature, recipes, VHS tapes, and XP media
description=[*]Inventory-selection and context-menu cleanup
description=[*]Property-driven realistic ladders with contextual direction resolution
description=[*]Discoverable Ladder → Climb Ladder submenu using the same revalidated native traversal request for ascent and descent
description=[*]Bounded third-party ladder-property registration without per-map UI patches
description=[*]Independent sandbox controls for gameplay features
description=[*]Fail-closed one-handed melee/firearm pair classification foundation with third-party providers
description=[*]Exact actor-root, nested, world, vehicle, and corpse references for authority-validated storage actions
description=[/list]

description=[h2]Ecosystem Integration[/h2]
description=[list]

description=[*]Supports verified vanilla and third-party workflows through original compatibility adapters
description=[*]Has no universal hard dependency
description=[/list]

description=[h2]Compatibility and Known Limitations[/h2]
description=[list]
description=[*]Requires Project Zomboid Build 42.20.3 or newer; the current installed Steam build is not runtime-validated
description=[*]The Mod ID is now B47ANCEDEssentials. Update client/server mod lists and dependent integrations together; do not enable the old and new identities together
description=[*]Sandbox options now use B47ANCEDEssentials. Existing presets do not migrate automatically; review intended settings before using an existing save
description=[*]Dedicated synchronization, reconnects, persistence, restarts, controller and split-screen behavior require native acceptance tests
description=[*]Independent-hand support is equipment classification only; no dual-wield attacks, reloads, animations or input integration are enabled
description=[*]Heavy-object APIs are a provider foundation, with no generic physics or production movement provider
description=[*]General batch-transfer transport is not automatically invoked by a storage UI
description=[/list]
